# README – Testes de Software

**Aluna:** Gabriela de Oliveira
**Turma:** ____2IG-DS_______

Nesta atividade da Aula 1, aprendemos sobre os fundamentos dos **Testes de Software**, como erro, defeito (bug), falha, testes funcionais e não funcionais e os níveis de teste: unitário, integração, sistema e aceitação.

Também analisamos o caso da **TechSolutions**, que possui um aplicativo de eventos acadêmicos. Durante a atividade, analisamos o cálculo do desconto dos ingressos. Para um ingresso de **R$ 100,00**, o desconto de 10% deveria deixar o valor em **R$ 90,00**, que foi o resultado retornado pelo código.

A atividade ajudou a entender como os testes podem encontrar problemas no código e verificar se o sistema está funcionando corretamente.
